# Imágenes de Trabajos

Guarda las imágenes en la carpeta indicada y usa estos nombres exactos para que
aparezcan automáticamente en las tarjetas del portafolio:

- `publicaciones/catalogo-corporativo.jpeg`
- `publicaciones/produccion-editoria.jpeg`
- `papeleria/cuadernos-personalizados.jpeg`
- `promocional/material-promocional.jpeg`

Se recomienda usar imágenes horizontales de buena resolución. Si tus imágenes
tienen otra extensión, actualiza la ruta correspondiente en `css/styles.css`;
los comentarios de `index.html` muestran qué imagen corresponde a cada tarjeta.
